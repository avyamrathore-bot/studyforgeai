# StudyForge AI — Downloadable Files & Package Index

Here are the downloadable assets and files generated for StudyForge AI:

---

### 1. Downloadable Files

1. **Full Application Source Code (ZIP Archive)**:
   - **File:** `studyforge-ai.zip` (in the artifacts directory)
   - **Contents:** Complete TypeScript, React 19, Tailwind CSS v4, Express server, Gemini 3.8 Flash integration, Concept Map engine, Photo Solver, Gamification & Quiz systems.
   - **How to run locally:**
     ```bash
     unzip studyforge-ai.zip -d studyforge-ai
     cd studyforge-ai
     npm install
     npm run dev
     ```

2. **Complete CBSE & ICSE Study Revision Guide & Model Answers**:
   - **File:** `studyforge_cbse_icse_revision_guide.md`
   - **Contents:** Full syllabus summaries, balanced chemical equations, redox rules, 3-mark & 5-mark board exam questions, model marking scheme answers, and Mendelian genetics cross ratios.

3. **In-App PDF Export**:
   - Inside the running application, click the **"PDF Export"** or **"Export PDF"** button on the top navigation bar or notes page to instantly download an offline, formatted PDF revision booklet (`StudyForge_[Topic]_[Board].pdf`) directly to your computer.
